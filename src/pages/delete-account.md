# 계정 삭제 안내

시행일: 2026년 4월 10일

## 앱 내에서 직접 삭제하기

Grameow 앱에서 직접 계정을 삭제할 수 있습니다.

1. 앱 하단 탭에서 **마이페이지** 이동
2. 화면 하단 **회원 탈퇴** 버튼 탭
3. 삭제 확인 다이얼로그에서 **확인** 선택

계정 삭제는 즉시 처리되며 복구할 수 없습니다.

## 이메일로 삭제 요청하기

앱 접근이 어려운 경우 이메일로 요청할 수 있습니다.

- **이메일**: [grameowapp@gmail.com](mailto:grameowapp@gmail.com)
- **제목**: 계정 삭제 요청
- **내용**: 가입 시 사용한 이메일 주소

요청 수신 후 **7일 이내**에 처리됩니다.

## 삭제되는 데이터

계정 삭제 시 아래 데이터가 영구적으로 삭제됩니다.

| 데이터 항목 | 삭제 시점 |
|---|---|
| 이메일 주소, 닉네임 | 즉시 |
| 학습 진도, 퀴즈 결과, 연속 학습일 | 즉시 |
| 기기 정보, 앱 사용 기록 | 즉시 |

## 법령에 따른 보관 데이터

관련 법령에 따라 일부 기록은 일정 기간 보관 후 파기됩니다.

- 계약 또는 청약철회에 관한 기록: **5년**
- 소비자 불만 또는 분쟁처리에 관한 기록: **3년**
